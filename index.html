Getting the painting images

The images come from your own copy of Minecraft. They are tiny (16 pixels per block), so open them here rather than in a photo viewer, which blurs them.

Java Edition (PC)
  1. Open your .minecraft folder. On Windows, press Win+R and type %appdata%\.minecraft. On Mac it is ~/Library/Application Support/minecraft.
  2. Go to versions, then the version folder, for example 1.21.4.
  3. Copy the .jar file somewhere else, rename the copy to end in .zip, and open it.
  4. Go to assets/minecraft/textures/painting/. Each painting is its own PNG, named after it, like kebab.png or wanderer.png.
Bedrock Edition (phone, console, Windows)
  1. Download the official Bedrock sample resource pack from Mojang's GitHub (Mojang/bedrock-samples).
  2. Open resource_pack/textures/painting/kz.png. All paintings share this one sheet.
  3. Upload it here, then open “Crop a section” and enter the painting's position and size in pixels.
